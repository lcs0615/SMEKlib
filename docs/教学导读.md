# SMEKlib 中文教学导读

本导读面向首次接触 SMEKlib 的读者，帮助理解库中主要目录、典型算法流程与练习顺序。请在阅读任意 `.m` 文件前先查看其开头的中文注释，随后结合本导读定位相关章节。

## 学习路径建议
1. **快速浏览示例**：`Examples/` 目录提供从几何建模到电磁分析的完整工程案例，可快速了解库的整体能力。
2. **了解网格生成**：进入 `SMEKlib/Mesh Generation/` 与 `SMEKlib/Mesh/`，学习如何构建有限元网格以及常用的数据结构。
3. **掌握矩阵装配**：阅读 `SMEKlib/Fast Basic Matrix Assembly/` 与 `SMEKlib/Classes/Matrix Assembly/`，理解稀疏矩阵构建、积分点遍历等核心算法。
4. **研究材料模型**：`SMEKlib/Nonlinear Materials/` 收录了铁磁、永磁体等材料的非线性处理方式，是分析真实电机的关键环节。
5. **扩展到机电耦合**：`SMEKlib/Rotor Movement/`、`SMEKlib/Point-Source Model/` 与 `SMEKlib/Winding Configuration/` 展示了转子运动、电流激励与绕组建模的实践。
6. **后处理与可视化**：最终在 `SMEKlib/Plotting and Post-Processing/` 以及 `SMEKlib/Classes/Plotting and Post-Processing/` 目录内学习结果展示方法。

## 目录逐项说明

### Examples/
- **作用**：提供从简单矩形线圈到完整电机分析的脚本，演示典型工作流。
- **推荐阅读**：先从 `Examples/GettingStarted` 系列入手，再尝试高阶示例如 `Examples/IPM_Motor`。

### SMEKlib/Mesh Generation/
- **关键文件**：`build_mesh.m`、`meshRefinement.m` 等脚本展示几何描述与自动划分策略。
- **教学重点**：理解参数化几何输入、边界条件标记以及与 `Mesh/` 模块的接口。

### SMEKlib/Mesh/
- **关键文件**：`triangulation.m`、`MeshObject.m` 等实现网格对象与拓扑关系查询。
- **教学重点**：掌握节点、边、单元编号的组织方式以及与矩阵装配的耦合。

### SMEKlib/Fast Basic Matrix Assembly/
- **关键文件**：`assembleStiffnessMatrix.m`、`elementMatrices.m` 等函数。
- **教学重点**：学习有限元矩阵装配的矢量化实现与性能优化技巧。

### SMEKlib/Classes/Elements and Shape Functions/
- **关键文件**：`TriangularElement.m`、`ShapeFunction.m`。
- **教学重点**：理解形函数评估、数值积分与元素刚度矩阵的计算流程。

### SMEKlib/Classes/Matrix Assembly/
- **关键文件**：`Assembler.m`、`MatrixBuilder.m`。
- **教学重点**：掌握装配调度、稀疏结构预分配以及多物理耦合的扩展接口。

### SMEKlib/Classes/Mesh/
- **关键文件**：`Mesh1D.m`、`Mesh2D.m` 等类。
- **教学重点**：理解不同维度网格类的差异以及如何管理边界集合。

### SMEKlib/Classes/Workflow/
- **关键文件**：`SimulationCase.m`、`PostProcessor.m`。
- **教学重点**：了解从输入参数到后处理的流程封装方式。

### SMEKlib/Nonlinear Materials/
- **关键文件**：`bhCurve.m`、`permeabilityModel.m`。
- **教学重点**：学习磁化曲线插值、牛顿迭代更新与滞后建模策略。

### SMEKlib/Winding Configuration/
- **关键文件**：`defineWinding.m`、`slotAssignment.m`。
- **教学重点**：理解绕组分布、相序以及与电路方程耦合的接口。

### SMEKlib/Rotor Movement/
- **关键文件**：`updateRotorPosition.m`、`slidingBand.m`。
- **教学重点**：掌握转动体网格的重映射与转矩计算流程。

### SMEKlib/Point-Source Model/
- **关键文件**：`pointCurrentSource.m`、`fieldEvaluation.m`。
- **教学重点**：了解集中电流源与磁矢势场的耦合处理。

### SMEKlib/Plotting and Post-Processing/
- **关键文件**：`plotField.m`、`exportVTK.m`。
- **教学重点**：掌握常见结果展示、曲线导出与动画生成技巧。

### SMEKlib/Conductor Decomposition/
- **关键文件**：`decomposeConductors.m`、`mergeConductors.m`。
- **教学重点**：研究多股导体的几何细分与物性参数映射。

### SMEKlib/gwrap/
- **说明**：包含与外部几何工具交互所需的接口脚本，阅读前请先了解 `Mesh Generation` 中的示例。

## 教学练习建议
1. **基础练习**：修改 `Examples` 中的简单模型，观察网格细分与矩阵装配结果的变化。
2. **进阶练习**：在 `Nonlinear Materials` 中替换磁化曲线，验证牛顿迭代收敛特性。
3. **综合练习**：结合 `Rotor Movement` 与 `Winding Configuration`，构建带有速度控制的动态仿真案例。

## 附录：术语对照
- **Element**：有限元单元 —— `SMEKlib/Classes/Elements and Shape Functions/`
- **Assembler**：矩阵装配器 —— `SMEKlib/Classes/Matrix Assembly/Assembler.m`
- **Post-processing**：后处理 —— `SMEKlib/Plotting and Post-Processing/`

阅读过程中如需查找特定文件，请使用 MATLAB 的 `which` 或 `help` 命令，亦可在本仓库根目录下执行 `rg <关键字>` 进行全文检索。
